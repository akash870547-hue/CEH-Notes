# Module 16: Hacking Wireless Networks

## Exam focus
Understand IEEE 802.11 basics, SSID/BSSID, channels, WPA2/WPA3, authentication, encryption, rogue access points, WPS risks, and wireless segmentation.

## Lab workflow
1. Confirm the lab adapter or supplied packet capture; do not monitor networks without authorization.
2. Identify SSID/BSSID, channel, security mode and signal information using the permitted OS/lab tools.
3. Review router configuration for WPA2-AES/WPA3, unique admin credentials, updated firmware and disabled unused features.
4. Inspect supplied captures for management/authentication and suspicious rogue-AP indicators.
5. Document finding, evidence and a defensive recommendation.

## Practical concepts
- SSID is the network name; BSSID identifies an access-point radio interface.
- WPA2/WPA3 are security protocols; a hidden SSID is not a meaningful substitute for encryption.
- Rogue AP risk can be reduced with enterprise wireless monitoring, 802.1X where appropriate and managed configurations.
- Avoid deauthentication or credential-capture actions outside a specifically authorized isolated exercise.

## Self-check
1. What is the difference between SSID and BSSID?
2. Why is MAC filtering not sufficient protection?
3. What wireless security mode is configured?
4. What evidence suggests an unknown/rogue AP?
5. How should a guest/IoT WLAN be segmented?
